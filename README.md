### Aim

To identify UX problem statements, select appropriate user research methods, and create user personas for two different UX project scenarios.

### Algorithm

1. Start.
2. Select two UX project scenarios: **Health App** and **E-Commerce Website**.
3. Identify the target users and their pain points.
4. Write 1–2 UX problem statements using the given template.
5. Select suitable UX research methods such as surveys, interviews, and usability testing.
6. Justify the selected research methods based on user needs.
7. Create at least two user personas for each scenario.
8. Include demographics, goals, behaviors, pain points, and motivations in each persona.
9. Document the findings and prepare the lab report.
10. Submit the GitHub repository URL along with the lab report PDF.
11. Stop.
